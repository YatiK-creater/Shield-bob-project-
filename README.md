# 🛡️ PhishShield — Cybersecurity Dashboard

A beginner-friendly cybersecurity web dashboard built entirely in **Python 3** using only the standard library.  
No external packages. No database. One file. Runs in any browser.

---

## 📸 What You'll See

| Section | Description |
|---|---|
| **Stat Cards** | Live counts — Safe ✅, Phishing 🚨, Suspicious ⚠️ |
| **Detection Charts** | 3 bar charts comparing Safe / Suspicious / Phishing by type |
| **Records Table** | First 10 detection records with time, username, type, content, result, and reason |
| **Security Alerts** | Collapsible panel with 15 flagged alerts, risk levels, and detection reasons |

## 🧠 How It Works

```
shield.py
│
├── PHISHING_KEYWORDS     ← 11 strong phishing indicators (e.g. "verify-account", "amaz0n")
├── SUSPICIOUS_KEYWORDS   ← 9 warning patterns (e.g. "bit.ly", "earn $", "download.exe")
│
├── detect(content)       ← Checks content with if statements → returns result + reason
│
├── RAW_RECORDS           ← 20 fictional records (no result yet)
├── RECORDS               ← RAW_RECORDS after running detect() on each one
├── ALERTS                ← Filtered RECORDS (Phishing + Suspicious only)
│
├── build_table_rows()    ← Turns RECORDS into HTML table rows
├── build_alert_rows()    ← Turns ALERTS into HTML alert cards
├── build_charts()        ← Draws 3 horizontal bar charts using HTML divs
│
└── HTTPServer            ← Listens on port 8080, sends the page to the browser
```

## 🔍 Detection Rules

### Phishing Keywords (High Risk 🔴)
These are strong indicators of a malicious attempt:

| Keyword | Why It's Phishing |
|---|---|
| `verify-account` | Fake account verification to steal credentials |
| `verify ssn` | No real service asks for SSN by message |
| `fakesite.com` | Obvious fake domain |
| `amaz0n` / `paypa1` | Typosquatting — letters replaced with numbers |
| `account will be closed` | Urgency threat to panic the user |
| `nflx-alert` / `prize-hub` | Impersonating trusted brands |
| `irs-refund` / `secure-dropbox-files` | Government/cloud brand impersonation |

### Suspicious Keywords (Medium Risk 🟡)
These are warning signs — not definitely malicious, but worth reviewing:

| Keyword | Why It's Suspicious |
|---|---|
| `bit.ly` | Shortened URL hides the real destination |
| `earn $` | "Earn money fast" scam pattern |
| `download.exe` | Executable files via message = malware risk |
| `guaranteed` / `300%` | Unrealistic financial promises |
| `update delivery` | Fake parcel delivery scam |
| `click link` | Vague link with no context |

## ⚠️ Important Notice

> These alerts are generated by **keyword pattern matching only**.  
> A Suspicious or Phishing flag **does not automatically prove** a cyber attack has taken place.  
> It means the content matched a known warning pattern and should be **reviewed by a human** before any action is taken.  
> False positives are possible.
